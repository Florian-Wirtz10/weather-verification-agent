# 这个文件夹怎么用

这不是一个能运行的项目，是一个"空骨架"——只包含容器配置和一些占位文件，不含任何具体业务代码。用来快速开一个新项目。

## 步骤

1. 把整个 `template/` 文件夹复制到 Mac 上你想放新项目的地方，改成新项目的名字，例如：

   ```bash
   cp -r template ~/projects/我的新项目
   ```

2. 打开 `.devcontainer/devcontainer.json`，把第一行 `"name": "PROJECT_NAME_HERE"` 改成新项目的名字。

3. 打开 `pyproject.toml`，把 `name`、`description` 改成新项目的信息。

4. 打开 `README.md`，把标题和说明改成新项目的实际内容。

5. 用 VS Code 打开这个新文件夹，选择 "Reopen in Container"（重新在容器中打开），等它自动装好环境。

6. 把 `.env.example` 复制一份改名成 `.env`，填入你真实的 API key（`.env` 不会被提交到 git，放心填）。

7. 开始在里面新建业务代码文件夹（比如 `core/`、`data/` 之类，按你项目实际需要来起名），每个文件夹的 `__init__.py` 里写一两句话说明这个文件夹是干嘛的。

## 用完这份说明之后

新项目建好、跑起来之后，把这个 `TEMPLATE_USAGE.md` 文件删掉就行，它只是给"建项目"这一步看的，不是给项目本身用的。

## 以后想更新这份模板

如果之后又发现了新的、值得所有项目都用上的配置改进（比如又发现了什么安全隐患、又想固定一个新工具版本），回到这个天气项目里的 `template/` 文件夹改一次，以后新建项目就都能用上最新版本。
